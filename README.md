# 🪔 Diwali Sales Analysis

### 📊 Exploratory Data Analysis using Python

An Exploratory Data Analysis project based on Diwali sales data to understand customer purchasing behavior, demographics, regional performance, occupations, and product-category demand.

---

## 📌 Project Overview

This project analyzes Diwali sales data using Python to identify important patterns and trends in customer purchases.

The analysis focuses on:

* Customer gender distribution
* Age-group purchasing behavior
* State-wise order performance
* Occupation-wise customer orders
* Top 10 product categories
* Overall purchasing patterns

The objective is to transform raw sales data into meaningful business insights that can help understand customer demand and purchasing behavior.

---

## 🎯 Business Questions

The project answers the following business questions:

* Which gender contributes more to purchases?
* Which age group is the strongest customer segment?
* Which states generate the most orders?
* Which occupations have the highest order volume?
* Which product categories are most popular?

---

## 🛠️ Technologies & Libraries Used

* **Python**
* **Pandas** – Data loading, cleaning and analysis
* **NumPy** – Numerical operations
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical visualization
* **Jupyter Notebook** – Development environment
* **IPyWidgets** – Interactive components

---

## 📂 Project Workflow

### 1. Data Loading

The Diwali sales dataset is imported using Pandas and the initial records are inspected.

### 2. Data Understanding

The dataset is explored using:

* Dataset shape
* Column information
* Data types
* Missing-value analysis
* Descriptive statistics

### 3. Data Cleaning

The data-cleaning process includes:

* Identifying missing values
* Removing rows containing missing values
* Removing/handling unnecessary data
* Renaming columns where required

### 4. Exploratory Data Analysis

#### 👥 Gender Analysis

The project analyzes the distribution of customers by gender and compares purchasing participation between male and female customers.

#### 🎂 Age Group Analysis

Customer purchases are analyzed across different age groups to identify the strongest customer segment.

#### 📍 Regional Analysis

State-wise order performance is analyzed to identify regions generating higher order volumes.

#### 💼 Occupation Analysis

Customer orders are grouped by occupation to understand which professional groups contribute more to the order volume.

#### 🛍️ Product Category Analysis

Product categories are analyzed based on total orders, with a focus on the **Top 10 product categories**.

---

## 📊 Visualizations

The project includes visualizations such as:

* Gender Distribution Chart
* Age Group Sales Chart

* Occupation-wise Total Orders
* Top 10 Product Categories

These visualizations make it easier to identify trends and compare customer segments.

---

## 🔑 Key Insights

Based on the analysis:

* **Female customers** represent a larger share of buyers and show stronger purchasing activity.
* The **26–35 age group** is the strongest customer segment in the analysis.
* **Uttar Pradesh** shows the highest order activity among the analyzed states.
* Customers working in **IT, Aviation and Healthcare** contribute significantly to order volume.
* Product-category analysis highlights the **Top 10 categories** with the highest number of orders.

---

## 💡 Conclusion

The Diwali Sales Analysis demonstrates how Exploratory Data Analysis can be used to understand customer behavior and sales patterns.

The project provides insights into **who the customers are, where they are purchasing from, what occupations they belong to, which age groups are most active, and which product categories receive higher demand**.

These insights can support businesses in making better decisions related to customer targeting, product demand and regional sales strategies.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Make sure Python is installed.
3. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn ipywidgets
```

4. Open Jupyter Notebook:

```bash
jupyter notebook
```

5. Open:

```text
Diwali sales analysis 2.ipynb
```

6. Make sure **Diwali Sales Data.csv** is present in the same project folder.
7. Run the notebook cells sequentially.
